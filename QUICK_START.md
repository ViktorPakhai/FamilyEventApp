# Family Evening - Швидкий старт 🚀

## Запуск додатку

```bash
docker-compose up -d
```

## Доступ до додатку

### 👥 Для учасників події
**URL**: http://localhost

1. Введіть своє ім'я
2. Виберіть подію
3. Натисніть "Увійти"

**Функції:**
- Задати питання спікеру
- Грати в інтерактивні ігри

---

### 👨‍💼 Для адміністраторів
**URL**: http://localhost/admin/login

**Облікові дані:**
- Логін: `admin`
- Пароль: `password`

**Функції:**
- Створювати події
- Створювати ігри з питаннями
- Модерувати питання від учасників (зірочки)
- Активувати/деактивувати ігри

---

## Приклад роботи з додатком

### Створення гри:

1. Увійдіть в адмін панель (admin/password)
2. Перейдіть на таб "Ігри"
3. Заповніть форму:
   - Назва гри
   - Опис (необов'язково)
4. Натисніть "Створити гру"
5. Натисніть "Питання" біля створеної гри
6. Додайте питання:
   - Текст питання
   - 4 варіанти відповіді
   - Виберіть правильну відповідь
7. Натисніть "Увімкнути" щоб активувати гру

### Гра учасника:

1. Увійдіть як учасник
2. Натисніть "🎮 Грати в ігри"
3. Виберіть активну гру
4. Відповідайте на питання
5. Переглядайте результати

---
